================================================================================
CONFIGURACIÓN PARA PROBAR AMBAS APPS SIMULTÁNEAMENTE:
================================================================================

Opción A: Dos terminales diferentes
Terminal 1: cd toro-driver && npx expo start --port 8081
Terminal 2: cd toro-rider && npx expo start --port 8082

Opción B: Dos emuladores Android
- Crear dos AVD en Android Studio (Pixel_Driver y Pixel_Rider)
- Correr ambos emuladores
- Cada app se instala en su propio emulador

Opción C: Emulador + Dispositivo físico
- Driver en emulador
- Rider en teléfono real (o viceversa)

================================================================================
NOTAS IMPORTANTES:
================================================================================

1. BACKEND COMPARTIDO: Ambas apps usan el mismo backend/API, no hay que duplicarlo

2. CLERK AUTH: Ambas apps pueden usar el mismo proyecto de Clerk, solo necesitan las mismas API keys

3. NEON DATABASE: Base de datos compartida, no duplicar

4. STRIPE: Configuración compartida

5. GOOGLE MAPS API: Misma API key para ambas

6. DEEP LINKING: Cada app tiene su propio scheme:
   - toro-driver://
   - toro-rider://

================================================================================
BENEFICIOS DE SEPARAR:
================================================================================

1. Bundle más pequeño (cada app solo tiene lo que necesita)
2. Mejor rendimiento (menos código cargado)
3. Fácil de probar ambos roles simultáneamente
4. Actualizaciones independientes
5. Permisos más específicos (driver necesita location siempre, rider solo cuando busca)
