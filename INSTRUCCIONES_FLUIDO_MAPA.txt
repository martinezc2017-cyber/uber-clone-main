ARCHIVO 1: hooks/navigation/useLocation.ts
================================================================================

/**
 * useLocation - GPS tracking hook optimizado para navegación
 *
 * Responsabilidades:
 * - Pedir permisos de ubicación
 * - Watch position con alta precisión
 * - Proveer posición actual, velocidad, y heading GPS
 * - Filtrar ubicaciones default del emulador
 * - Throttle updates para rendimiento
 * - PAUSAR GPS cuando app está en background (ahorra batería)
 */

Características clave:
- Location.Accuracy.BestForNavigation
- timeInterval: 100ms
- distanceInterval: 0.5m
- AppState listener para pause/resume cuando app va a background
- Detección de ubicación default del emulador (37.4219983, -122.084)
- Fallback a Arizona si detecta emulador

Código del AppState handling:
```typescript
const handleAppStateChange = (nextState: AppStateStatus) => {
  isActive = nextState === "active";
  if (nextState === "active") {
    startWatching(); // Resume GPS
  } else {
    stopWatching();  // Pause GPS (saves battery!)
  }
};
```

ARCHIVO 2: hooks/navigation/useNavigationCamera.ts
================================================================================

/**
 * useNavigationCamera - Cámara suave para navegación
 *
 * Responsabilidades:
 * - Calcular punto de look-ahead (vehículo en la parte inferior de la pantalla)
 * - Interpolación suave de heading
 * - Throttle camera updates para rendimiento
 * - Proveer config para MapView.animateCamera()
 * - requestAnimationFrame para 60fps suaves
 */

Características clave:
- lookAheadKm: 0.00055 (~55m adelante)
- pitch: 65 grados
- zoom: 17.5
- updateInterval: 50ms mínimo entre updates
- minMovement: 0.2m para trigger update
- minHeadingChange: 0.5 grados
- animationDuration: 30ms

TÉCNICA CLAVE - requestAnimationFrame:
```typescript
const raf = typeof requestAnimationFrame !== "undefined"
  ? requestAnimationFrame
  : (cb: () => void) => setTimeout(cb, 16);

// Batches multiple updates into one frame (60fps)
const animateCamera = useCallback((mapRef, position, heading) => {
  const config = getCameraConfig(position, heading);
  if (!config) return false;

  // Queue for next frame
  pendingAnimationRef.current = { mapRef, config };

  // Schedule RAF if not already scheduled
  if (rafIdRef.current === null) {
    rafIdRef.current = raf(executeAnimation);
  }
  return true;
}, []);
```

ARCHIVO 3: hooks/navigation/useRoute.ts
================================================================================

/**
 * useRoute - Fetching de rutas y snapping
 *
 * Responsabilidades:
 * - Fetch route desde OSRM (Open Source Routing Machine)
 * - Decode polyline
 * - Simplificar ruta (menos puntos = mejor rendimiento)
 * - Detectar off-route
 * - Avanzar pasos de navegación
 */

Características:
- Usa OSRM: https://router.project-osrm.org/route/v1/driving/
- Simplificación de polyline con Douglas-Peucker
- Off-route detection (>50m de la ruta)
- Step advancement basado en proximidad

ARCHIVO 4: hooks/navigation/useVehicleState.ts
================================================================================

/**
 * useVehicleState - Heading y movimiento del vehículo
 *
 * Responsabilidades:
 * - Calcular bearing de movimiento desde cambios de posición
 * - Transiciones suaves de heading (sin rotación brusca)
 * - Proveer heading estable para cámara y marker
 * - Prioridad: movementBearing > gpsHeading > previousHeading
 */

Características:
- maxHeadingDelta: 45 grados máximo por update
- minMovementForBearing: 0.3m mínimo para calcular bearing
- limitTurn() para transiciones suaves

ARCHIVO 5: app/driver/premium-nav-v2.tsx (REFACTORIZADO)
================================================================================

Optimizaciones implementadas:

1. EXPO-KEEP-AWAKE - Mantener pantalla encendida:
```typescript
import { activateKeepAwakeAsync, deactivateKeepAwake } from "expo-keep-awake";

useEffect(() => {
  activateKeepAwakeAsync("navigation").catch(() => {});
  return () => deactivateKeepAwake("navigation");
}, []);
```

2. APPSTATE - Pausar operaciones cuando app va a background:
```typescript
useEffect(() => {
  const subscription = AppState.addEventListener("change", (nextState) => {
    isAppActiveRef.current = nextState === "active";
    if (nextState === "active") {
      activateKeepAwakeAsync("navigation").catch(() => {});
    } else {
      deactivateKeepAwake("navigation");
    }
  });
  return () => subscription.remove();
}, []);
```

3. INTERACTIONMANAGER - Defer trabajo pesado:
```typescript
InteractionManager.runAfterInteractions(() => {
  if (isAppActiveRef.current && location.position) {
    route.fetchRoute(location.position, navTarget);
  }
});
```

4. MAPVIEW OPTIMIZADO:
```typescript
<MapView
  // Padding agresivo - recorta bordes, menos tiles
  mapPadding={{ top: 120, right: 0, bottom: 200, left: 0 }}

  // Limitar zoom - menos detalle = render más rápido
  minZoomLevel={15}
  maxZoomLevel={18}

  // Cache tiles en Android
  cacheEnabled={Platform.OS === "android"}

  // Desactivar todo lo innecesario
  showsBuildings={false}
  showsTraffic={false}
  showsIndoors={false}
  showsPointsOfInterest={false}
  toolbarEnabled={false}
  loadingEnabled={false}
/>
```
